# Met Museum Landing

Simple responsive landing page inspired by the Metropolitan Museum of Art.

## 🔗 Demo

https://alyonashunevych.github.io/met-museum-landing/

## 🛠️ Tech Stack

* HTML
* SCSS

## 📱 Features

* Responsive layout

## 🚀 Run locally

```bash
git clone https://github.com/alyonashunevych/met-museum-landing.git
cd met-museum-landing
npm install
npm start
```
